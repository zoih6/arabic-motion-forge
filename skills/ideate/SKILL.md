# Ideate (creative engine — think like a director, not a menu)

The engine (tools/direct.py) supplies STRUCTURE; you supply CREATIVE RISK. A concept is only approved when it could not have come from a template site.

## Persona panel (write these three verdicts in `ideas.md`, 2–4 lines each)
- **Art director:** What is the ONE image/metaphor this film is about? If you can't picture the poster, the concept is empty. Kill the obvious first: list 3 clichés for this topic, then forbid them in the film.
- **Director:** What happens in the first 2 seconds, and what tension keeps frames 3–15? One signature move, repeated and escalated. Storyboard beats before software.
- **Social strategist:** Native format instinct — hook before context, motion that reads muted and on a phone at 20%, one frame worth screenshotting (name the timestamp). Aspect/pacing convention for the platform stated in style.json.

## Method (hard sequence)
1. Extract the user's REAL desire first: their words all preserved (reframe gate), then "what they didn't say but clearly want" — 3 bullets.
2. Run `tools/direct.py --topic ... --project .` — it now returns hook bank + wild cards + cliché blacklist. You may OVERRIDE its random picks with a stronger combo; document why.
3. Cross-pollinate: force one WILD CARD (unrelated domain) into each concept — integration must be structural (a mechanic borrowed), never a costume.
4. Cliché check each concept against `catalog/dictionaries/creative-bank.json` blacklist; a concept surviving 3+ clichés must be re-cut, not excused.
5. Escalation test: for the chosen concept, write `escalation: opening→development→final frame` each strictly more intense than the last; a flat profile fails.
6. Hand to creative-direction: approved concept becomes the axis spine + `signature_move` + `forbidden_tropes` fields in style.json (check_project requires them in full mode).

Never present the user three flavors of the same safe idea. If all three concepts could've been generated by a template, generate again harder — boring is a bug.
