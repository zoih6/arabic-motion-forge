# delivery

اقرأ `../AGENTS.md` أولًا. لا تحمّل هذا المسار إلا حين يحتاجه الطلب.

## الإجراء
1. افحص مساحة اللقطة والقرص مباشرة. اترك هامشًا؛ الكاش والتبعيات قد لا يبقيان بين الجلسات.
2. لا تحمل أفلام الأمثلة عند التثبيت. ضع المصدر الخفيف في git والوسائط الكبيرة في Releases أو وجهة مصرح بها.
3. سجل SHA وحجم ومدة كل جزء، وانتظر تأكيد الرفع قبل اعتباره محفوظًا. لا تحذف الأصل بعد الرفع.
4. لا تنقل مادة إلى خارج اللقطة قبل التحقق من نسخة بعيدة وسجل استعادة واضح. الكاش وحده ليس أرشيفًا.
5. لا تنشر مواد مشروع جديد في مستودع المهارة. اطلب الوجهة والخصوصية والصلاحية عند الحاجة.
6. الأسرار في ذاكرة العملية فقط. لا .env ضمن الحزمة ولا token في remote URL أو README أو أوامر committed.
7. عند الإغلاق: تحقق من الروابط وبصمات الملفات، حدّث الحالة، اعرض الملف الرئيسي، ثم أغلق publisher.

## المخرجات
manifest للحفظ، سجل recovery، روابط مؤكدة، وحالة مشروع صادقة.

اقرأ [الموارد](../reference/resource-policy.md) و[النشر](../reference/publishing.md).


## عقد التحقق

اربط القرار بالبيانات الفعلية في project.json وlayer-plan.json، ثم اختبر الحالة قبل الحركة وأثناءها وبعدها. مصدر الحركة القابل للتشغيل في `runtime/core.mjs` و`runtime/canvas.mjs`؛ آليات القاموس في `catalog/motions.json`. لا تستنتج دعمًا من الاسم وحده، ولا تنسب إلى مراجعة آلية ما لم تفحصه.
