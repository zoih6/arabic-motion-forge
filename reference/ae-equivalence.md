# الآلية الفعلية مقابل اسم أداة After Effects

| المفهوم | التنفيذ هنا | الحد |
|---|---|---|
| Alpha Track Matte | destination-in بين سطح المحتوى وقناع مستقل | اختبر 0/1 والأزمنة الوسطية؛ ليس تشغيل AE |
| Luma Matte | Rec.709 موزون على sRGB في بكسلات القناع | نموذج لون معلن، لا مطابقة كل working spaces |
| Trim Paths | طول قوس ومسار جزئي ورأس محسوب من النهاية نفسها | polylines وBezier sampled؛ لا path topology سحري |
| Text Animators | range/stagger للكلمات والسطور مع تشكيل كامل | الحروف العربية المتصلة محظورة في التحويل الفردي الافتراضي |
| Graph Editor | مخطط قيمة ومشتق سرعة لمنحنى قابل للضبط | مختبر تشخيصي، لا واجهة Adobe الأصلية |
| Motion Blur | متوسط عينات زمنية ضمن shutter interval | عدد العينات ونموذج RGBA محددان؛ ليس Gaussian ثابتًا |
| Morph | interpolation لرؤوس متقابلة | يرفض عدم التطابق؛ ليس crossfade |
| Parent Controls | ضرب مصفوفات مع قنوات أبناء مستقلة | لا يبرر تجميع كل المشهد |
| 3D / Flip | يتطلب محركًا/adapter مثبتًا | غير مدعوم افتراضيًا كـ native 3D؛ لا تسوّق scaleX كدوران حقيقي |
| Write On | مسارات ضربات مؤلفة مسبقًا | لا تحول outline الخط إلى قلم مزعوم |

اقرأ القاموس ونتائج الاختبارات. `implemented` يشير إلى النطاق المحدد وليس إلى التطابق البتّي مع Adobe.
